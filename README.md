# self-refine-video

<!-- Experimental code integrated with NVIDIA Cosmos Predict2.5 for self-refinement in video generation / world-model pipelines. -->
This branch contains experimental self-refinement code integrated with NVIDIA Cosmos Predict2.5 for video generation and world-model–style pipelines.

## Installation

For environment setup, dependencies, and general installation instructions, please follow the upstream NVIDIA Cosmos Predict2.5 repository:

- https://github.com/nvidia-cosmos/cosmos-predict2.5

## P&P inference

For Predict-and-Perturb (P&P) inference usage, refer to the provided script in this workspace:

- `cosmos-predict2.5/inference_pnp.sh`
